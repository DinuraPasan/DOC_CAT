HC74595 API Reference

Complete Arduino API reference for Texas Instruments / NXP SN74HC595 8-bit serial-in, parallel-out shift registers.
Version 1.2.0 SPI / GPIO Protocol SN74HC595 DOC_CAT Library

Overview

The HC74595 library provides high-performance, low-RAM-overhead control over cascaded SN74HC595 shift registers. It simplifies output pin manipulation, supports dynamic numerical and character binary visualizations, multiplexed 7-segment display rendering (integer/floating point), and pre-built visual LED chase/flash animation routines.

Basic Example

Below is a minimal initialization and setup example using the HC74595 class included within the DOC_CAT library.

Arduino 
// Include DOC_CAT header file
#include <DOC_CAT.h>

// Pin Definitions
uint8_t SER = 10;     // Arduino pin connected to pin 14 (DS / data) of the 74HC595
uint8_t RCLK = 11;    // Arduino pin connected to pin 12 (ST_CP / latch) of the 74HC595
uint8_t SRCLK = 12;   // Arduino pin connected to pin 11 (SH_CP / clock) of the 74HC595
uint8_t NUMOFIC = 2;  // Number of cascaded 74HC595 ICs

// Instantiate HC74595 controller instance
HC74595 Shift(NUMOFIC, SER, RCLK, SRCLK);

void setup() {
    // Direct output bit manipulation without updating shift register immediately
    Shift.NoUpdate(0, HIGH);
    
    // Commit buffered bit states to physical IC outputs
    Shift.Update();
}

void loop() {
    // Main application loop
}

Initialization & Constructor

HC74595(uint8_t IC, uint8_t SER, uint8_t RCLK, uint8_t SRCLK)
Constructor
Initializes the HC74595 shift register controller instance, configures pin modes, and dynamically allocates internal output memory buffers based on the number of cascaded ICs.
Arduino 
// Parameters:
//   IC    - Total number of daisy-chained 74HC595 shift registers
//   SER   - Serial data pin connected to pin 14 (DS) of the 74HC595

#include <DOC_CAT.h>

// Instantiate object for 2 cascaded ICs using Arduino pins 10, 11, and 12
HC74595 Shift(2, 10, 11, 12);

Core Output Control Methods

void Update()
Core Control
Transfers all output bit states buffered in memory to the cascaded 74HC595 shift registers and updates their physical hardware pins.
Arduino 
// Latch memory buffer content to physical hardware pins
Shift.Update();
void NoUpdate(int index, bool state)
Core Control
Changes the target state (HIGH/LOW) of a specific output bit index in RAM memory without updating the physical shift registers.
Arduino 
// Parameters:
//   index - Target pin index across cascaded ICs (0 to [IC * 8] - 1)
//   state - Desired state (HIGH or LOW / true or false)

Shift.NoUpdate(0, HIGH); // Stage output 0 state to HIGH in memory buffer
Shift.Update();        // Apply changes to hardware outputs
void SetAll(bool state)
Core Control
Sets all outputs across all cascaded shift registers to the specified state (HIGH or LOW) and immediately updates the physical IC outputs.
Arduino 
// Parameters:
//   state - Target state for all output pins (HIGH or LOW)

Shift.SetAll(true);  // Turn ON all shift register outputs
delay(1000);
Shift.SetAll(false); // Turn OFF all shift register outputs

Binary Conversion Methods

void NumberToBinary(int value, bool reverse)
Data Conversion
Converts a 16-bit integer value into binary output states across cascaded shift registers and immediately updates outputs.
Arduino 
// Parameters:
//   value   - Integer numerical value (0 to 65535) to render in binary format
//   reverse - Bit-mapping direction (true = direct byte write, false = inverted bit map)

Shift.NumberToBinary(12345, true); // Convert integer 12345 to binary LED array output
void CharacterToBinary(char value, bool reverse)
Data Conversion
Converts an ASCII character into its binary bit representation across shift registers and updates outputs.
Arduino 
// Parameters:
//   value   - ASCII character (e.g., 'A', 'Z') to convert to binary
//   reverse - Bit-mapping direction selector (true or false)

Shift.CharacterToBinary('A', true); // Display binary representation of ASCII 'A'

Display Control
Displays a custom bit pattern on a multiplexed seven-segment display module.
Arduino 
// Parameters:
//   segments      - Bitmask specifying illuminated segments (0b00000000 to 0b11111111)
//   digitPosition - 0-based digit index to illuminate
//   digitCount    - Total number of multiplexed digits in hardware module

LED Animation & Visual Effects

void LEDFlash(int duration, uint8_t pin)
Animation Effect
Flashes a specified output pin ON and OFF for the designated millisecond duration.
Arduino 
// Parameters:
//   duration - Flash duration in milliseconds
//   pin      - Target shift register output pin index

Shift.LEDFlash(100, 0); // Flash output pin 0 for 100 ms
void LEDSequence(int duration, uint8_t pin)
Animation Effect
Progressively turns ON and OFF pins sequentially from the specified highest pin index down to pin 0.
Arduino 
// Parameters:
//   duration - Delay between pin transitions in milliseconds
//   pin      - Highest starting pin index in the downward sequence

Shift.LEDSequence(10, 15); // Run sequential fill and clear pattern from pin 15 to 0
void LEDChase(uint8_t repetition, int duration, uint8_t startPin, uint8_t endPin, bool reverse)
Animation Effect
Executes a chasing light animation sequence across a range of pins in ascending or descending direction.
Arduino 
// Parameters:
//   repetition - Number of times to repeat the chase animation
//   duration   - Delay between LED state transitions in milliseconds
//   startPin   - Beginning output pin index of range
//   endPin     - Ending output pin index of range
//   reverse    - Direction: true = descending (end to start), false = ascending (start to end)

Shift.LEDChase(5, 100, 0, 15, true); // Repeat reverse chase effect 5 times across pins 0 to 15
void LEDRandomFlash(uint8_t repetition, int duration, uint8_t startPin, uint8_t endPin)
Animation Effect
Randomly selects and flashes individual pins ON and OFF within a defined output range.
Arduino 
// Parameters:
//   repetition - Number of random flashes to execute
//   duration   - Delay time in milliseconds
//   startPin   - Minimum pin index boundary
//   endPin     - Maximum pin index boundary

Shift.LEDRandomFlash(30, 100, 0, 15); // Execute 30 random flashes between pins 0 and 15
void LEDRandomToggle(uint8_t repetition, int duration, uint8_t startPin, uint8_t endPin)
Animation Effect
Randomly turns outputs ON and OFF within a pin range to generate pseudo-random patterns.
Arduino 
// Parameters:
//   repetition - Number of toggle iterations to perform
//   duration   - Timing delay in milliseconds between toggles
//   startPin   - Lower pin index boundary
//   endPin     - Upper pin index boundary

Shift.LEDRandomToggle(30, 100, 0, 15); // Perform 30 random pin state toggles across outputs 0 to 15
void LEDMirrorChase(uint8_t repetition, int duration, uint8_t startPin, uint8_t endPin, uint8_t divisor)
Animation Effect
Runs a mirrored chasing light animation from both outer boundaries toward the center point of a designated pin range.
Arduino 
// Parameters:
//   repetition - Number of animation cycles to repeat
//   duration   - Transition delay in milliseconds
//   startPin   - Start pin boundary
//   endPin     - End pin boundary
//   divisor    - Divisor specifying span convergence ratio (typically 2 or 3)

Shift.LEDMirrorChase(5, 100, 0, 15, 2); // Run mirrored chase across 16 outputs using a divisor of 2
