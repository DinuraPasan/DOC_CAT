LP503X API Reference

Complete Arduino API reference for Texas Instruments LP5030 and LP5036 constant-current RGB LED drivers.
Version 1.2.0 I2C Protocol LP5030 / LP5036 DOC_CAT Library

Overview

The LP503X library provides high-level and low-level control of Texas Instruments LP5030 (30-channel) and LP5036 (36-channel) I²C LED drivers. It supports RGB color control, linear and logarithmic brightness adjustment, PWM dithering, banked color control, configurable LED current, and standby modes, along with register access and diagnostic functions for easy configuration and debugging in embedded applications.

Basic Example

Below is a minimal initialization example using the LP503X class with Arduino's standard Wire library.

Arduino 
// Include DOC_CAT header file
#include <DOC_CAT.h>

// Instantiate LP503X object with I2C address (0x30)
LP503X ledDriver(0x30);

void setup() {
    // Set up normal operating mode and enable logarithmic scaling
    ledDriver.normal_mode();
    ledDriver.logScale(true);
    
    // Set LED channel 0 color-mixing and brightness levels
    ledDriver.setColour(0, 255);    // Set color-mixing value to maximum
    ledDriver.setBrightness(0, 200); // Set intensity level to 200
}

void loop() {
    // Main application loop
}

Define Macro Hex Value Description
DEVICE_CONFIG0 0x00 Chip enable and standby mode control register

LED_CONFIG1 0x03 Bank assignment for LED modules 8 through 11
RESET 0x38 Software reset register (write 0xFF to reset)

Individual Channel Control Methods

void setColour(uint8_t LED, uint8_t value)
Individual Channel
Sets the color-mixing level of an individual LED output channel.
Arduino 
// Parameters:
//   LED   - Target LED output index (0-29 for LP5030, 0-35 for LP5036)
//   value - Desired color-mixing intensity level ranging from 0 to 255

ledDriver.setColour(0, 0xFF);    // Set LED channel 0 to maximum color-mixing level (0xFF)
uint8_t getColour(uint8_t LED)

Bank Control Methods

void setRGBbank(char colour, uint8_t value, uint8_t intensity)
Bank Control
Sets the color-mixing level and global brightness of an RGB color bank.
Arduino 
// Parameters:
//   colour    - Color bank selector ('R'/'r' for red, 'G'/'g' for green, 'B'/'b' for blue)
//   value     - Color-mixing level (0-255)
//   intensity - Global brightness level for enabled LED banks (0-255)

ledDriver.setRGBbank('R', 255, 200);    // Set red bank color-mixing to 255 and global intensity to 200
void setRGBbank(uint8_t red, uint8_t green, uint8_t blue, uint8_t intensity)
Bank Control
Sets the color-mixing levels of all RGB color banks simultaneously.
Arduino 
// Parameters:
//   red       - Red bank color-mixing level (0-255)
//   green     - Green bank color-mixing level (0-255)
//   blue      - Blue bank color-mixing level (0-255)
//   intensity - Global brightness level for enabled LED banks (0-255)

ledDriver.setRGBbank(255, 100, 50, 255);    // Set bank colors (Red=255, Green=100, Blue=50) and master intensity to 255
uint8_t getBankColour(char colour)

// Parameters:

// Returns:
//   uint8_t - Color-mixing level (0-255)

uint8_t bankG = ledDriver.getBankColour('G');    // Get color-mixing level for Green bank

Bank Control
Gets the global brightness level of all enabled LED banks.
Arduino 
// Returns:
//   uint8_t - Bank brightness level (0-255)

uint8_t bankBright = ledDriver.getBankIntensity();    // Get global brightness level for enabled LED banks
void setModule(uint8_t moduleID, bool enable)
Bank Control
Enables or disables an LED module for RGB bank control.
Arduino 
// Parameters:
//   moduleID - LED module selector (LED0_Bank_EN to LED11_Bank_EN for modules 0-11)
//   enable   - Set to true to enable or false to disable bank control

ledDriver.setModule(2, true);    // Enable bank control for LED module 2
bool getModule(uint8_t moduleID)
Bank Control
Checks whether an LED module is enabled for RGB bank control.
Arduino 
// Parameters:
//   moduleID - LED module selector (LED0_Bank_EN to LED11_Bank_EN for modules 0–11)
// Returns:
//   bool     - True if bank control is enabled; otherwise, false

bool isBanked = ledDriver.getModule(2);    // Check bank control status for LED module 2
